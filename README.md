# 🛋️ Landing Page Limpeza de Estofados

Landing page desenvolvida para geração de leads e captação de clientes para serviço de limpeza de estofados.


## 🚀 Objetivo

Criar uma página estratégica para atrair clientes interessados no serviço e facilitar o contato direto.


## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript


## 🎯 Foco do projeto

- Apresentação clara do serviço
- Destaque de benefícios (higienização, conforto, saúde)
- Prova de valor (antes e depois / diferenciais)
- Botão de contato direto via WhatsApp
- Estrutura otimizada para conversão


## 📱 Responsividade

Interface adaptada para:
- Smartphones
- Tablets
- Desktop


## 💡 Resultado esperado

Gerar mais contatos e solicitações de orçamento para o serviço.

✔ Projeto finalizado (ou em evolução)
